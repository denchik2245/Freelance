# Новые обложки портфолио FL.ru (22.11.2026)

Тот же стиль, что у обложек Kwork (`kwork-covers/`): десктоп + телефон на цветном фоне кейса, без текста и значков. Формат FL — квадрат 600×600, выгружено в 2x (1200×1200 PNG).

Десктоп у всех начинается на одной высоте (y = 75) и уходит за нижний край квадрата (низ рамки на y = 642, по образцу Дениса на «Студии разработки»). Телефон у всех на одной высоте. Где скриншот страницы кончается раньше, продолжение залито цветом нижнего края страницы. У прототипов в десктопе верх полной страницы из секции «Прототипы» (рамки «… — Прототип 1920»). **Исключение — первые экраны (00, 08, 16, 17, 18, 31) и аудиты (32–35):** у них есть только первый экран, поэтому десктоп не растягивается. Его высота равна первому экрану: 281 px, у «Учебного центра» 300, у аудитов 313. Десктоп и телефон стоят по центру квадрата по вертикали (центр на y = 300, корпус телефона на y = 90), так их выровнял Денис 22.11.2026.

Источник: Figma «Материалы (Copy)», страница «Кейсы», секция «Обложки FL — десктоп + телефон (новые)» (под секцией Kwork, x = −12 000, y = 15 840). Ряды те же, что у Kwork. У каждой рамки уже стоит экспорт PNG 2x.

Номера файлов совпадают с `kwork-covers/`; 32–35 — аудиты, на Kwork их обложек в папке нет.
